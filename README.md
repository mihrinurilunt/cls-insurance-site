# Çağdaş Lider Sigorta - Professional Insurance Agency Web Site

A modern, high-performance, and responsive web application developed for **Çağdaş Lider Sigorta**, a professional insurance agency based in Istanbul. This project serves as a digital gateway for customers to explore insurance services, get quotes, and access 24/7 support.

## 🎯 Project Goals

* **Establish Digital Presence:** Transitioning a local agency into the digital space with a professional corporate identity.
* **User-Centric Experience:** Providing an intuitive UI/UX where users can easily understand complex insurance products like Kasko, Traffic, Health, and BES.
* **Direct Communication:** Integrated contact systems (WhatsApp, Phone, EmailJS/Formspree) to ensure seamless lead generation.
* **Trust & Authority:** Showcasing partner logos and a comprehensive FAQ section to build credibility with potential clients.

## 🚀 Technical Stack

* **Frontend:** React.js with TypeScript for robust, type-safe development.
* **Styling:** Tailwind CSS for a modern, utility-first responsive design.
* **Icons:** Lucide-React for clean and consistent iconography.
* **Components:** Radix UI / Shadcn UI for accessible and interactive components (Accordions, Tooltips, Modals).
* **Form Handling:** Integrated with **Formspree** for reliable backend-less email processing.
* **Deployment:** Hosted on **Vercel** with automated CI/CD pipelines.

## ✨ Key Features

* **Interactive Partner Grid:** A grayscale-to-color logo grid featuring Turkey's leading insurance providers (Allianz, AXA, Ak Sigorta, etc.).
* **Service Information Hub:** Detailed sections for different insurance categories with professional iconography.
* **Functional Contact Form:** Validated form with real-time email notifications.
* **Comprehensive FAQ:** An accordion-style FAQ section to address common customer inquiries and improve SEO.
* **Emergency Contact Bar:** A sticky/prominent call-to-action for 24/7 damage support.
* **SEO Optimized:** Custom meta tags, structured `sitemap.xml`, and Google Search Console integration for high search engine visibility.

## 🛠️ Installation & Setup

1. **Clone the repository:**
```bash
git clone https://github.com/your-username/cls-insurance-site.git

```


2. **Install dependencies:**
```bash
npm install

```


3. **Run the development server:**
```bash
npm run dev

```


4. **Build for production:**
```bash
npm run build

```
